# Contributing Guidelines

Thank you for your interest in contributing to **KADatabase**! To ensure a smooth collaboration, please follow these steps:

### 1. Report Bugs or Suggest Features via Issues
Before submitting a Pull Request (PR), please **raise an Issue first**.
* This prevents duplicate work if I am already working on the same feature.
* It allows us to discuss the implementation details before you write code.

### 2. Wait for Approval
After opening an Issue, please wait for a response before starting work.
* I aim to respond within **1-2 days**.
* *Note: As I am a student, my response time may vary during exam periods. Thank you for your patience!*

### 3. Submission Process
* Fork the repository.
* Create a new branch for your feature.
* Submit a Pull Request referencing the Issue number.

We look forward to your contributions!
